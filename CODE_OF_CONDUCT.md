# 행동 강령 / Code of Conduct

본 프로젝트는 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 을 채택합니다.

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

전문은 위 링크에서 확인할 수 있으며, 한국어 번역본은 [Contributor Covenant Korean](https://www.contributor-covenant.org/ko/version/2/1/code_of_conduct/) 에서 제공됩니다.

The full text is available at the link above; an official Korean translation is provided at [Contributor Covenant Korean](https://www.contributor-covenant.org/ko/version/2/1/code_of_conduct/).

---

## 신고 / Reporting

부적절한 행동을 목격하거나 경험한 경우, 프로젝트 GitHub 이슈로 비공개 신고가 어렵다면 메인테이너에게 직접 메일로 연락 주세요.

If you witness or experience unacceptable behavior, please contact the project maintainers — open a private report via the GitHub repository, or email the maintainers directly if a private channel is needed.

신고 채널 / Reporting channel: <https://github.com/seolcoding/korean-stat-mcp/issues>

---

## 적용 범위 / Scope

본 강령은 프로젝트 공간(GitHub Issues, PRs, Discussions 등)과 프로젝트를 대표하는 모든 공개 활동에 적용됩니다.

This Code of Conduct applies within all project spaces (GitHub Issues, PRs, Discussions, etc.) and in any public space when representing the project.
