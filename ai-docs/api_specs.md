데이터 처리 스크립트 개발
먼저, 데이터 처리의 핵심인 파이썬 스크립트부터 시작하겠습니다.

주요 기능:

메타데이터 기반 자동화: 이전에 생성한 kosis_metadata_final.json 파일을 읽어, 파일 안의 모든 통계표에 대해 데이터 수집을 자동 수행합니다.
동적 API URL 생성: 각 통계표의 ORG_ID, TBL_ID 등의 정보를 사용하고, 확인된 대로 objL1과 itmId에는 'ALL'을 사용하여 동적으로 API 요청 URL을 만듭니다.
최적 수록주기 탐색: '월(M) > 분기(Q) > 반기(H) > 년(Y)' 순서로 API를 호출하여 해당 통계표가 제공하는 가장 세분화된 주기의 데이터를 찾아냅니다.
데이터 변환 및 가공: KOSIS API로부터 받은 원시 데이터를 우리가 처음 정의했던 최종 JSON 구조(title, description, data, 등)로 변환합니다. item 필드는 '분류명 - 항목명'처럼 의미있는 이름으로 조합됩니다.
LLM 연동 준비: 최종 JSON의 title과 description 등은 우선 메타데이터의 정보로 채우고, 추후 Gemini 같은 LLM으로 고도화할 수 있도록 주석으로 표시해두었습니다.
개별 파일 저장: 처리된 각 통계표는 결과폴더/{TBL_ID}_processed.json 형식의 개별 파일로 저장하여 관리 편의성을 높입니다.
