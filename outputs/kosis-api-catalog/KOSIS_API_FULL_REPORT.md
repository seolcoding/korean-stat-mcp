# KOSIS OpenAPI 기능/API/조회 가능 통계 전체 보고

- 생성일: 2026-04-29
- 실제 사용 API: `statisticsList.do`, `statisticsSearch.do`
- 전체 순회 뷰: `MT_ZTITLE`, `MT_OTITLE`, `MT_GTITLE01`, `MT_RTITLE01`
- 인증키는 환경변수에서 읽어 호출에만 사용했고 산출물에는 저장하지 않았습니다.
- 전체 재귀 순회 결과: **54,944행**, 중복 제거 후 **50,061개 통계표**
- 뷰별 수집량: 국내통계 주제별 49,252개, 국내통계 기관별 4,890개, e-지방지표 257개, 국제/북한통계 545개
- 통합검색 API 보강 목록: **4,997개 통계표**

## 1. 사용 가능한 API 기능
| 구분 | 엔드포인트 | 제공 형식 | 가능한 작업 |
|---|---|---|---|
| 통계목록 | `statisticsList.do` | JSON, SDMX | 분류 트리와 통계표 목록 탐색 |
| 통계자료 | `Param/statisticsParameterData.do / statisticsData.do` | JSON, SDMX | 수치 데이터 조회 |
| 대용량 통계자료 | `statisticsBigData.do` | SDMX, XLS | 사전 등록 기반 대용량 조회 |
| 통계설명자료 | `statisticsExplData.do` | JSON, XML | 조사 목적, 작성 유형, 법적 근거, 조사 주기 등 설명 |
| 통계표설명/메타 | `statisticsData.do?method=getMeta` | JSON | 통계표명, 기관, 분류, 항목, 기간, 단위, 출처, 갱신일 |
| KOSIS 통합검색 | `statisticsSearch.do` | JSON | 키워드 기반 통계표 검색과 링크/경로 보강 |
| 통계주요지표 | `pkNumberService.do 등` | JSON, XML | 주요지표 설명, 목록, 상세 시계열 |

## 2. 통계자료 조회 기능
- 일반 수치 조회: `Param/statisticsParameterData.do?method=getList` 또는 `statisticsData.do?method=getList`
- 필수/핵심 파라미터: `orgId`, `tblId`, `itmId`, `objL1`~`objL8`, `prdSe`, `startPrdDe`, `endPrdDe`, `newEstPrdCnt`
- 주기: `Y` 연간, `M` 월간, `Q` 분기, `S/H` 반기, `F` 다년, `IR` 불규칙
- 제한: 분당 1,000회, 일반 통계자료 요청당 40,000셀, 대용량 XLS 200,000셀

| 주요지표 API | 지표 설명, 목록, 이름 검색, 고유번호별 상세 시계열 |
